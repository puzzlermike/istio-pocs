# Istio PoCs

Collection of Istio PoCs.

## Ambient Rate Limiting

The folder `usecases/001-ambient-rate-limiting` contains a PoC for Istio Ingress Gateway rate limiting using Ambient mode.

## Ambient Multi-Cluster

The folder `usecases/002-ambient-multi-cluster` contains an Istio Ambient Multi-Cluster mesh PoC.
